# Support

This page covers the current `main` branch of the local Bun and Pi swarm
workspace.

## Getting support

When reporting a problem, include the affected commit, the command or workflow
that failed, the smallest reproducible example, and relevant local logs with
credentials and personal data removed. Do not share provider tokens, Pi
credentials, private configuration, or unredacted run exports.

Open a [GitHub issue](https://github.com/T-Py-T/SwarmSpindle/issues) for bugs
and questions. For setup and troubleshooting, start with
[Operations](docs/OPERATIONS.md). Report security problems through
[SECURITY.md](SECURITY.md) instead of a public issue.
